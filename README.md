PujoPath
========

A professional Durga Puja companion application.

Features
--------
- Pandal discovery
- Interactive map
- Nearby pandals
- Metro integration
- Pandal hopping planner
- Puja calendar
- Mahalaya
- Puja music
- Favorites
- Bengali/English support
- Responsive PWA

Tech Stack
----------
Next.js
React
TypeScript
Tailwind CSS
PostgreSQL-ready architecture

Development
-----------
npm install
npm run dev

Production
----------
npm run build
npm run start

Testing
-------
npm run test
